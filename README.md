# Поиск автозапчастей

Тестовое приложение для поиска автозапчастей по артикулу.

Пользователь вводит артикул, выбирает производителя и получает список предложений и аналогов с ценой и остатком на складе.

## Стек

- React
- Redux Toolkit
- Bootstrap
- Express

## Запуск

```bash
npm install
```

Скопируйте `.env.example` в `.env` и добавьте ключ Favorit Parts:

```env
FAVORIT_API_KEY=ваш_ключ
PORT=3001
```

Запустите проект:

```bash
npm run dev
```

Клиент будет доступен на `http://localhost:5173`.
